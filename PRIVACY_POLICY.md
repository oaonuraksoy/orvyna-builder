## 3. Core Principles & Local-First Architecture
1. **Local-First Processing:** Your project files, web application wrappers, source code, icon graphics, and configuration templates reside locally on your physical machine or device.
2. **Zero Sale of Personal Data:** We have never sold, and will never sell, lease, or broker your personal information or application data to third parties, data aggregators, or advertising brokers.
3. **Data Minimization:** We only process the absolute minimum data required to deliver core functionality, licensing validation, and optional build automation services.
4. **Transparent Permissions:** Native device capabilities (such as camera, microphone, or precise location) are only requested at runtime when an explicit user action requires them.

---

## 4. Information We Do (and Do Not) Collect

### 4.1. Information Kept Purely Local (Not Transmitted to Our Servers)
- **Project Files & Source Code:** When configuring or building an application with Orvyna App Studio, all configurations, web bundles, HTML/CSS/JS assets, keystores, and certificate files remain strictly on your local disk.
- **Biometric Data:** If biometric authentication (Touch ID, Face ID, Android BiometricPrompt) is enabled in an application generated by Orvyna Mobile Runtime, biometric verification occurs strictly within the device's hardware Secure Enclave or Trusted Execution Environment (TEE). Neither Orvyna nor any remote server ever accesses your biometric scans or raw templates.

### 4.2. Information Processed for Licensing & Operations
- **License Validation:** If you activate a commercial tier or verify your license, our relay service verifies the cryptographic signature of the license key and associated platform receipts. This verification uses one-way pseudonymous identifiers and does not store personal behavioral history.
- **Support Communication:** If you contact us directly via email, we keep records of your inquiry, correspondence, and technical details to resolve your issue.

### 4.3. Information We NEVER Collect
- Credit card or bank account details.
- Keystroke logging or screen recording.
- Unencrypted secrets or private signing credentials.
- Browsing history from websites viewed inside webview wrappers.

## 5. Mobile Runtime Device Permissions
When you run applications powered by the **Orvyna Mobile Runtime**, native capabilities are guarded by operating system permissions. These are triggered **only if** the wrapped web application explicitly requests them and the user grants explicit consent:

| Permission | iOS Key / Android Permission | Purpose & Scope |
|---|---|---|
| **Camera** | `NSCameraUsageDescription`<br>`android.permission.CAMERA` | Allows capturing photos or scanning QR/barcodes inside the app if initiated by the user. Never records in the background. |
| **Microphone** | `NSMicrophoneUsageDescription`<br>`android.permission.RECORD_AUDIO` | Required for voice search, real-time voice notes, or WebRTC calls. Activated solely upon active user interaction. |
| **Location** | `NSLocationWhenInUseUsageDescription`<br>`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION` | Utilized for geocoding or map functionality within wrapped web portals. Only accessed while the application is in foreground use. |
| **Storage / Photos** | `NSPhotoLibraryUsageDescription`<br>`READ_MEDIA_IMAGES`, `READ_EXTERNAL_STORAGE` | Allows selecting media files or saving downloaded documents. |
| **Biometrics** | `NSFaceIDUsageDescription`<br>`USE_BIOMETRIC`, `USE_FINGERPRINT` | Optional security gate for locking/unlocking the app. Processed entirely on-device by Apple Secure Enclave or Android KeyStore. |
| **Notifications** | `POST_NOTIFICATIONS`<br>APNs token | Enables optional push messaging only if configured and granted by the user. |

Users retain total control and can revoke these permissions at any time via system settings on iOS (`Settings > Privacy`) and Android (`Settings > Apps > Permissions`).

## 5. Cihaz İzinleri ve Çalışma Zamanı (Runtime) Erişimi
**Orvyna Mobile Runtime** motorunu kullanan uygulamalar, yalnızca sarmalanan web sitesi/uygulama talep ettiğinde ve kullanıcı açık onay verdiğinde aşağıdaki donanım izinlerini ister:

| İzin | Platform Tanımı | Kullanım Amacı ve Kapsamı |
|---|---|---|
| **Kamera** | `NSCameraUsageDescription`<br>`android.permission.CAMERA` | Kullanıcı fotoğraf çekmek, belge yüklemek veya QR kod taramak istediğinde devreye girer. Arka planda çalışmaz. |
| **Mikrofon** | `NSMicrophoneUsageDescription`<br>`android.permission.RECORD_AUDIO` | Sesli arama, sesli komut veya WebRTC görüşmeleri için kullanıcı başlatınca aktif olur. |
| **Konum** | `NSLocationWhenInUseUsageDescription`<br>`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION` | Harita veya konum tabanlı servisler için yalnızca uygulama ön plandayken ve izin verildiğinde kullanılır. |
| **Depolama / Fotoğraflar** | `NSPhotoLibraryUsageDescription`<br>`READ_MEDIA_IMAGES`, `READ_EXTERNAL_STORAGE` | Cihazdan dosya/görsel yükleme veya indirilen belgeleri kaydetme amacıyla kullanılır. |

| **Bildirimler** | `POST_NOTIFICATIONS` | Kullanıcı onay verdiğinde ve yapılandırıldığında anlık bildirim göndermek için kullanılır. |
